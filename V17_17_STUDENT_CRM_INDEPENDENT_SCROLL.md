# V17.17 Student CRM Independent Scroll

## Scope
- Student / Parent CRM editor scrolls independently.
- Student list scrolls independently while its search toolbar remains visible.
- Table header remains visible inside the list.
- Desktop and landscape tablet layouts use the split-scroll viewport.
- Stacked tablet/mobile layouts keep normal page scrolling.
- No student data, CRM actions, permissions, cloud sync, or business calculations changed.
