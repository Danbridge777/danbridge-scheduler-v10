# V17.29 Summer Camp Split-Week Pricing and Date Continuation

- Added a split-week pricing mode for monthly summer-camp registration.
- The operator can choose how many starting weeks use the front weekly rate.
- Remaining weeks use a separate back weekly rate.
- Fees are calculated only for calendar weeks containing at least one selected registration date.
- Selecting the same student and month automatically loads the existing registration.
- Existing selected dates remain checked, allowing additional dates to be selected and saved.
- Saving updates the original record instead of creating a duplicate registration.
- Legacy daily, fixed-weekly, and monthly pricing modes remain supported.
- Backup, import normalization, branch scoping, and cloud synchronization retain the new pricing fields.
